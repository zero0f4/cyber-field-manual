01 De Cyber Kill Chain (Lockheed Martin, 2011)

Klassiek 7-fasen-model uit Hutchins, Cloppert & Amin (LM, 2011). Veruit het bekendste mentale raamwerk om een gerichte aanval te beschrijven. Geadopteerd door MITRE ATT&CK (als grovere "tactic"-laag), Mandiant en NIST.

Origineel paper: "Intelligence-Driven Computer Network Defense Informed by Analysis of Adversary Campaigns and Intrusion Kill Chains".

De 7 fasen — uitgebreid per fase

1. Reconnaissance — Verkenning

Aanvaller verzamelt informatie over het doel: medewerkers, technologie, leveranciers, fysieke locatie, e-mail-domein.

Aanvaller doetOSINT (LinkedIn, Whois, Shodan, GitHub-leaks), DNS-recon, port-scans, social-media-scraping, dumpster-diving fysiek.
Typische toolsShodan, theHarvester, Maltego, recon-ng, Sherlock, Hunter.io, Sublist3r.
ATT&CKTA0043 Reconnaissance (T1589 Gather Victim Identity, T1592 Victim Host Info, T1596 Open Technical DBs)
DetectieLastig — meeste recon is passief. Wel: ongebruikelijke DNS-querie-patronen, scanning op rand-IPs, Shodan-monitoring eigen footprint.
DefenderReduceer aanvalsoppervlak: geen onnodige services publiek, e-mail-adressen niet rondsproeien, employee-OSINT-bewustzijn.

2. Weaponization — Wapen prepareren

Combineren van een exploit en payload tot een leverbare bom: een macro-document, gewapende PDF, weaponized installer, malicious OAuth-app.

Aanvaller doetCobalt Strike beacon genereren, Metasploit payload, custom loader, malicious office-document met VBA, ISO-container met LNK + scriptlet.
Typische toolsCobalt Strike, Metasploit, Sliver, msfvenom, MacroPack, Empire, custom packers/crypters.
ATT&CKTA0042 Resource Development (T1587 Develop Capabilities, T1588 Obtain Capabilities)
DetectieVoornamelijk extern — sandboxing, vendor-feeds, sample-hashes. Eigen telemetrie ziet hier niets.
DefenderThreat-intel-feeds, sandbox-pre-detonation, blocklisten op file-hash + macro-policy. Office-macro's standaard uit.

3. Delivery — Aflevering

De bom bereikt het doel: phishing-mail, drive-by-website, USB-stick, malicious tweet/link, supply-chain-compromise.

Aanvaller doetSpear-phishing met bijlage, gehackte website met exploit-kit, USB-drop op locatie, watering-hole, OAuth-consent-flow.
Typische toolsGoPhish, EvilGinx, MailoTracking, evilQR, smishing-platforms.
ATT&CKTA0001 Initial Access (T1566 Phishing, T1189 Drive-by, T1091 Removable Media, T1566.002 Spearphishing Link)
DetectieE-mail-gateway (URL-rewriting, attachment-sandbox), DMARC-fail, awareness-meldingen.
DefenderE-mail-filtering, browser-isolation, MFA, DMARC/SPF/DKIM, awareness-training, phishing-simulaties.

4. Exploitation — Code uitvoeren

Slachtoffer triggert de payload: opent macro, klikt link, USB-stick autoruns, browser-zero-day vuurt af.

Aanvaller doetVBA-macro draait, JS in browser, exploit-kit chain, MFA-bypass via consent-grant, RDP-credential-stuffing succesvol.
Typische toolsCobalt Strike loader, ScrubCrypt, Donut shellcode, Bumblebee loader.
ATT&CKTA0002 Execution (T1059 Command/Scripting, T1204 User Execution, T1106 Native API)
DetectieEDR proces-tree (winword.exe → cmd.exe is verdacht), child-process van Office, rare PowerShell-encodings.
DefenderEDR/AV met behavior-detect, application allow-listing, attack-surface-reduction-rules (Defender ASR).

5. Installation — Voet aan de grond

Persistence creëren zodat reboot/uitloggen de toegang niet verbreekt.

Aanvaller doetScheduled task, service installeren, registry Run-key, WMI event-subscription, browser-extension, OAuth-app-permissions, golden ticket.
Typische toolsSharPersist, Empire-modules, Mimikatz, custom service-installers.
ATT&CKTA0003 Persistence + TA0004 Privilege Escalation (T1053 Scheduled Task, T1543 Service, T1547 Boot/Logon Autostart)
DetectieSysmon Event 1 (process create), 11 (file create), 12-13 (registry), 22 (DNS) — corrigeer met Sigma-rules.
DefenderEDR baseline-monitoring, AppLocker, autorun-monitoring, golden-ticket-detectie via Microsoft Defender for Identity.

6. Command & Control (C2) — Kanaal opzetten

Communicatiekanaal opzetten naar de aanvaller-server. Hoort vaak verstopt in legitiem verkeer (HTTPS, DNS, Slack-API, Telegram).

Aanvaller doetCobalt Strike beacon, Sliver implant, custom HTTPS-tunnel, DNS-tunneling, domain-fronting via CDN, Slack/Discord/Telegram als C2.
Typische toolsCobalt Strike, Sliver, Mythic, ngrok, Cloudflare-tunnels, dnscat2.
ATT&CKTA0011 Command and Control (T1071 Application Layer Protocol, T1572 Protocol Tunneling, T1090 Proxy)
DetectieJA3/JA4-fingerprints, beacon-analyse (regelmatige interval), DNS-anomalie, ongebruikelijke HTTPS-bestemmingen.
DefenderEgress-filtering, DNS-monitoring (Pi-hole / NextDNS / SIEM), TLS-inspection waar mag, threat-intel-feeds met C2-IPs.

7. Actions on Objectives — Doel bereiken

Het uiteindelijke doel uitvoeren: data exfiltreren, ransomware uitrollen, sabotage, manipulatie, langdurig spioneren.

Aanvaller doetLateral movement → discovery → data-collection → exfiltratie via HTTPS naar cloud-storage; daarna ransomware-detonatie of stilte.
Typische toolsMimikatz/LSASS, BloodHound, AdFind, Rclone, MEGA-uploads, ransomware-binary (LockBit/Black Basta).
ATT&CKTA0007 Discovery, TA0008 Lateral Movement, TA0009 Collection, TA0010 Exfiltration, TA0040 Impact
DetectieVeel bulk-data-uitstroom, DNS-storms, abnormale PSExec/WMI-traffic, hongerige proces voor file-encryption.
DefenderEgress-DLP, network-segmentation, immutable backups, EDR ransomware-protection, IR-runbook geoefend.
Verdedigings-implicatie: hoe vroeger in de kill chain je breekt, hoe goedkoper. Reconnaissance afdekken kost weinig; ransomware-detonatie afhandelen kost weken.

02 Courses of Action — D5/D7-matrix

De originele LM-paper definieert per fase 5 (later 7) defensieve acties:

ActieWatVoorbeeld
DetectWaarnemen dat het gebeurtSIEM-alert, EDR-detectie, NTA-alarm
DenyVerhinderen dat het luktFW-block, MFA-vereiste, application allow-list
DisruptOnderbreken tijdens uitvoerEDR isoleert host, kill-switch, session-revoke
DegradeVertragen / minder effectiefRate-limit, sandbox-vertraging, JIT-toegang
DeceiveValse informatie laten zienHoneypot, decoy-account, canary-token
Destroy(Mogelijk) aanvaller-tooling vernietigenTake-down via hosting-provider, sinkhole
ContainInsluitenNetwerk-segmentatie, host-isolation

Maak per fase een matrix: voor elke kill-chain-fase, welke acties heb ik beschikbaar? Gaten zien er meteen uit.

03 Mandiant Attack Lifecycle

Variant met expliciete nadat-binnen-aanwezig-fasen: realistischer voor APTs die maandenlang lateral movement doen. 8 fasen:

  1. Initial Recon
  2. Initial Compromise
  3. Establish Foothold
  4. Escalate Privileges
  5. Internal Recon
  6. Move Laterally
  7. Maintain Presence
  8. Complete Mission

Stappen 4-7 vormen een loop — APTs herhalen recon/move/escalate herhaaldelijk. Belangrijk verschil met de strikt lineaire LM-chain.

04 Unified Kill Chain (Paul Pols, 2017)

Combineert LM Cyber Kill Chain + Mandiant Attack Lifecycle + MITRE ATT&CK in 18 fasen, opgedeeld in 3 hoofd-blokken.

Fase 1: Initial Foothold

  1. Reconnaissance
  2. Weaponization
  3. Delivery
  4. Social Engineering
  5. Exploitation
  6. Persistence
  7. Defense Evasion
  8. Command & Control

Fase 2: Network Propagation

  1. Pivoting
  2. Discovery
  3. Privilege Escalation
  4. Execution
  5. Credential Access
  6. Lateral Movement

Fase 3: Action on Objectives

  1. Collection
  2. Exfiltration
  3. Impact
  4. Objectives

Dit raamwerk is de most overlapping mapping naar ATT&CK; nuttig voor end-to-end threat-storytelling.
