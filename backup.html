01 3-2-1-1-0 — de moderne backup-regel

Klassiek 3-2-1 is in 2025+ niet meer voldoende. Ransomware versleutelt online backups mee. Modern: 3-2-1-1-0.

CijferWat
3Drie kopieën van je data (één productie + twee backups)
2Op twee verschillende media-typen (disk + cloud, disk + tape)
1Eén kopie offsite (geografisch gescheiden)
1Eén kopie offline of immutable (air-gapped, write-once, S3 Object Lock)
0Nul fouten in restore-test (regelmatig daadwerkelijk terugzetten)

Waarom immutable / air-gapped?

Ransomware-actoren proberen vóór encryptie eerst je backups te corrumperen — anders kan je gewoon herstellen. Tactieken:

  • Backup-server credentials stelen (vandaar: aparte admin-credentials voor backup)
  • Backup-shares versleutelen via SMB
  • Cloud-snapshots verwijderen via API-key-misbruik

Tegenmaatregel: backups die ná schrijven niet meer gewijzigd of verwijderd kunnen worden — door object-lock (AWS S3, Azure Blob immutable), tape, of fysiek air-gapped.

RTO en RPO — wat is realistisch?

TermVraagVoorbeeld
RPO (Recovery Point Objective)Hoeveel dataverlies (in tijd) is acceptabel?RPO = 1u → backup elk uur
RTO (Recovery Time Objective)Hoeveel downtime is acceptabel?RTO = 4u → systeem moet binnen 4u draaien

Hoe lager RTO/RPO, hoe duurder de oplossing. Per systeem en data-classificatie inschatten — niet "alles moet binnen 1 uur".

Restore-test — minimaal kwartaal

  • Selecteer ad random een server / dataset / mailbox
  • Restore op testomgeving
  • Verifieer integriteit + bruikbaarheid
  • Documenteer doorlooptijd (= je werkelijke RTO)
  • Doe minstens 1× per jaar een full disaster recovery oefening
Als je nog nooit hebt teruggezet, weet je niet of het werkt. Schrödinger's backup: de status is onbekend tot je het probeert.

Ransomware-preparedness checklist

  • 3-2-1-1-0 backup-strategie geïmplementeerd
  • Backup-credentials gescheiden van productie-AD
  • EDR op alle endpoints + servers
  • Network-segmentatie tussen werkstations en servers
  • Geen RDP open vanaf internet zonder MFA + ZTNA
  • SMB-signing aan, SMBv1 uit
  • Application allow-listing op kritische systemen
  • IR-plan met "ransom: wel/niet betalen?" beleid en juridische aanspreekpunt
  • Cyber-insurance met ransomware-clausule (let op: veel polissen sluiten betaling uit of vereisen toestemming)
  • Tabletop-oefening: "het is woensdag 03:00, alle servers zijn versleuteld"
