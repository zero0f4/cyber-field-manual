01 MITRE ATT&CK

Open kennisbank van tactieken (waarom), technieken (hoe) en procedures (variant) van cyberaanvallers. Onmisbaar als gedeeld vocabulaire tussen detectie, threat-intel en red team.

14 Enterprise-tactieken in volgorde van een typische aanval:

TA0043 Reconnaissance TA0042 Resource Development TA0001 Initial Access TA0002 Execution TA0003 Persistence TA0004 Privilege Escalation TA0005 Defense Evasion TA0006 Credential Access TA0007 Discovery TA0008 Lateral Movement TA0009 Collection TA0011 Command & Control TA0010 Exfiltration TA0040 Impact

Techniek-hiërarchie

  • Technique (Txxxx) — bv. T1059 Command and Scripting Interpreter
  • Sub-technique (Txxxx.yyy) — bv. T1059.001 PowerShell, T1059.003 Windows Command Shell
  • Procedure — concrete uitvoering door een specifieke actor of malware-sample, beschrijvend in het rapport

Bijbehorende objecten

Mitigations (Mxxxx)
~40 generieke verdedigingen, bv. M1042 Disable or Remove Feature, M1026 Privileged Account Management.
Data Sources (DSxxxx)
~40 telemetriebronnen, bv. DS0009 Process, DS0017 Command. Geeft per techniek aan wát je moet loggen.
Detections
Beschrijvende richtlijn per techniek hoe te detecteren — input voor Sigma-regels.
Groups (Gxxxx)
~150 actor-groepen met aliassen, bekende technieken en software.
Software (Sxxxx)
~700 malware/tooling-entries (Mimikatz, Cobalt Strike, etc.).
Campaigns (Cxxxx)
Specifieke geclusterde aanvalscampagnes, gekoppeld aan een groep.

Werken met ATT&CK

  • Threat-intel: noteer in elk rapport welke ATT&CK-techniek-IDs (Txxxx) zijn waargenomen.
  • Detectie-coverage: ATT&CK Navigator-layer per detectie-regel — heatmap-gewijs zien waar je gaten zitten.
  • Red & purple team: emuleer technieken (Atomic Red Team, Caldera), meet detection latency.
  • Sub-domains: ATT&CK Mobile, ATT&CK ICS, MITRE ATLAS (AI), MITRE Engenuity Evaluations.

02 MITRE D3FEND

Defensieve tegenhanger van ATT&CK: kennisgraaf van detectie-, isolatie-, deceptie- en evictie-technieken, expliciet gekoppeld aan ATT&CK-technieken via "digital artifacts" (proces, file, account, netwerkstroom). Beheerd door MITRE, NSA-funded.

6 D3FEND-tactieken:

Model

Asset/identity/network/data inventarisatie.

Harden

Patching, baselines, allow-listing, encryptie.

Detect

Logs, FIM, EDR, netwerkanalyse, SIEM-correlaties.

Isolate

Segmentatie, sandboxing, microsegmentatie, ZTNA.

Deceive

Honeypots, decoy-credentials, canary-tokens.

Evict

Account-revocatie, session-termination, host-isolation.
