01 Sharing standards

Threat intelligence is alleen waardevol als het deelbaar is. Dit zijn de open formats waarop het CTI-ecosysteem leunt.

STIX 2.1 — Structured Threat Information Expression

JSON-schema-gebaseerd model van OASIS. Beschrijft entiteiten als objecten met relaties — net als een grafiek.

SDO's (Domain Objects, 18): attack-pattern, campaign, course-of-action, grouping, identity, indicator, infrastructure, intrusion-set, location, malware, malware-analysis, note, observed-data, opinion, report, threat-actor, tool, vulnerability.

SCO's (Cyber Observables, 18): file, ipv4-addr, domain-name, url, network-traffic, process, software, user-account, x509-certificate, e-mail-message, etc.

SRO's (Relationship Objects, 2): relationship, sighting.

Elke STIX-object heeft een id (UUID), created, modified, spec_version, eigen velden + external_references.

TAXII 2.1 — Trusted Automated eXchange

HTTPS-REST-API om STIX-bundles op te halen en te plaatsen. Concepten:

  • Discovery — root-URL geeft beschikbare API-roots terug.
  • Collection — een logische set bundles (per feed of per onderwerp).
  • Channel — pub/sub-stijl push (optioneel).
  • Status — ophalen van pending / completed jobs.

MISP — Malware Information Sharing Platform

Open-source platform van CIRCL (Luxemburg). Werkt met:

  • Events — een rapport / incident, met taggable attributes.
  • Attributes — IoC-velden (md5, ip, domain, email, etc.) met type, category, comment.
  • Objects — gestructureerde groepen attributes (file, person, btc-transaction, ...).
  • Galaxies — taxonomieën van threat actors, malware-families, sectoren — gebaseerd op JSON-bestanden in misp-galaxy.
  • Taxonomies — gestandaardiseerde tag-namespaces (tlp, pap, admiralty, mitre-attack-pattern, ...).
  • Sightings — telling per attribute waar/wanneer het is waargenomen.

Sigma — generieke SIEM-detectieregels

YAML-schema (Florian Roth, Nextron) om detectieregels portable tussen SIEMs te definiëren. Vertaal naar Splunk SPL, Elastic ES|QL, Sentinel KQL, etc.

title: Suspicious PowerShell Encoded Command
id: 8a1b2c3d-...
status: experimental
description: Detects encoded PowerShell commands often used for obfuscation
logsource:
  product: windows
  service: sysmon
detection:
  selection:
    EventID: 1
    CommandLine|contains:
      - '-enc '
      - '-encodedcommand '
  condition: selection
falsepositives:
  - Legitimate scripts using encoded commands
level: medium
tags:
  - attack.execution
  - attack.t1059.001

YARA — pattern-matching

"The pattern matching swiss knife for malware researchers" (VirusTotal). Strings + boolean-condities op file-content of memory.

rule ExampleRAT
{
  meta:
    author = "analyst"
    description = "Example RAT loader pattern"
    date = "2026-04-30"
    hash = "abc123..."

  strings:
    $s1 = "C:\\\\Users\\\\Public\\\\Documents\\\\sys.dll" wide
    $s2 = { 90 90 EB 22 ?? ?? ?? CC }
    $hdr = "MZ" at 0

  condition:
    $hdr and (1 of ($s1, $s2)) and filesize < 2MB
}
